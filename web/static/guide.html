PRODUCT GUIDE · 产品使用说明

从原始文件到部门质检结果

本工具面向教务数据质检人员。选择业务、部门和月份后，系统自动识别文件、执行对应规则，并导出仅包含所选部门的数据。

本页目录 工具定位 上传前准备 操作步骤 月份与部门 结果与导出 常见问题
01 · WHAT IT DOES

工具定位

系统按业务类型决定质检范围。部门只需选择一次，不需要为班级信息和配课表重复选择。

班课业务

班级信息 + 班级配课表

上传三份班级信息和一份 classlesson 班级配课表。所选部门同时用于两类数据的筛选与导出。

高端业务

仅 PCLV 高端配课表

不上传、不检查班级信息。PCLV 的标化部门直接采用原表“标准部门名称”。

本工具用于发现疑似异常。涉及部门对应关系的内容会生成“部门组合核对”清单，由业务人员人工确认，不会直接计入异常。
02 · FILE CHECKLIST

上传前准备

业务文件格式要求
班班级配课表.xlsx / .xls必须为 classlesson 字段结构，不能上传 PCLV。
班本月及次月开课.csv / .xlsx / .xls三份班级信息的列名和列顺序必须一致。
班本月设班.csv / .xlsx / .xls系统自动合并为固定 Sheet，无需用户手工合并。
班本月结课.csv / .xlsx / .xlsCSV 可自动兼容 UTF-8、UTF-8 BOM、GB18030 编码。
高PCLV 高端配课表.xlsx / .xls必须包含 PCLV 字段结构；无需任何班级信息文件。

单次上传内容总大小不得超过 80 MB。建议直接使用系统导出的原始文件，不要自行删除列、修改表头或合并单元格。

03 · QUICK START

操作步骤

选择业务类型

选择“班课业务”或“高端业务”，页面会自动切换部门范围和文件入口。

确认质检部门

部门只选一次。班课同时应用于班级信息和配课表；高端只应用于 PCLV。

确认质检月份

默认显示电脑系统当前月份，也可手动改为历史月份或下月。

上传原始文件

班课上传四份文件，高端只上传一份 PCLV。支持点击选择和拖拽上传。

开始质检

按钮点亮后提交任务。文件较大时可能需要几十秒，请保持页面打开。

查看并下载结果

页面展示记录数、异常数和规则分布；下载 Excel 查看逐行异常反馈。

04 · SCOPE

月份与部门如何生效

质检部门

班课部门按系统生成的“标化部门”筛选；高端部门按 PCLV 的“标准部门名称”筛选。选择“全部部门”时保留全部数据。

质检月份

月份用于班级信息中的0人班封班范围，以及“未设置主带课教师”的已开课判断。最终以输入框显示的 YYYY-MM 为准。

例如选择 2026-08：0人班检查使用 2026-08-01 至 2026-08-31；主带课教师检查将开课日期不晚于 2026-08-31 的班级视为已开课范围。

05 · OUTPUT

结果文件说明

  • 质检参数：记录业务类型、质检月份和质检部门。
  • 部门汇总：展示班级信息、配课表的总记录数、异常记录数和异常率。
  • 班级信息质检：仅班课业务生成。
  • 配课质检-classlesson：班课业务生成。
  • 配课质检-pclv：高端业务生成。
  • 部门组合核对：列出管理部门与标准部门组合，供人工确认。

明细表首列“质检结果反馈”汇总该行命中的全部异常，多个异常用“+”连接，并使用黄色底、红色加粗字体突出显示。规则列中通常以 1 表示异常、0 表示正常。

06 · TROUBLESHOOTING

常见问题

无法识别配课表类型

检查是否选择了正确业务，以及文件是否保留原始表头。班课只能上传 classlesson，高端只能上传 PCLV。

所选部门不存在

说明上传文件经标化后没有该部门。核对部门选择、原表“标准部门”或“标准部门名称”。

三份班级信息无法合并

确认三份文件均已上传，并且列名、列数和列顺序完全一致。

历史月份仍按当前月判断

先确认页面月份显示正确。导出的“质检参数”Sheet 会记录本次真正使用的月份。
